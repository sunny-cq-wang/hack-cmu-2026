## 2. Demo script (2:00)

Pre-state: seeded demo user "Simon", pet "Biscuit" (real photo → sticker avatar), streak 5, today has breakfast logged, Biscuit fed once. Home screen open. Phone mirrored.

| t | Action | What judges see | Owner |
|----|--------------------|--------------------------|------|
| 0:00 | "People quit diets. Nobody forgets to feed their dog." | Home: avatar `okay`, score ring 62, streak 5 | P1 speaks |
| 0:15 | Tap Log → photograph the demo plate (pre-tested chicken + rice + broccoli) | Analyze sheet: 3 items, grams, kcal, iron/fiber chips | P2 |
| 0:40 | Edit rice 180 → 150 g, Confirm | Home: score jumps to 81, avatar animates to `thriving` | P1/P4 |
| 0:55 | Tap Pet → "Fed Biscuit" | Portion card 66 g, pet score 100, streak "today ✓" | P3 |
| 1:05 | Tap weigh-in, enter 13.7 kg | Adjustment toast "portion −5% → 63 g", weight chart with projected goal date | P3 |
| 1:25 | Hold Talk: "Biscuit, what should I have for dinner?" | Transcript, pet voice reply naming remaining kcal + fiber gap + a meal; avatar `talking` | P4 |
| 1:45 | Tap Plan | Tomorrow's 3 meals, "USDA‑verified" badge, gaps closed | P2 |
| 1:55 | Close: "Every number is server-computed, every photo is in Atlas, every user is Auth0, every AI call is Grok." | | P1 |

Do **not** show onboarding or avatar generation live; show the pre-generated three states in the slides with the original photo beside them.

## 3. Risk register

| Risk | Likelihood | Mitigation | Owner |
|------------------------|------|----------------------------|------|
| Venue wifi blocks/slows Grok vision | High | 8 s timeout → cached demo result for the 3 rehearsed plates; demo from phone hotspot | P2 |
| Native module breaks the dev build (Auth0/Rive/audio) | Medium | Build at T+1, again at T+12 and T+22; never upgrade packages after C3 | P1 |
| Imagine endpoint shape differs from plan | Medium | Verify at T+0; wrappers isolate the change; demo assets pre-generated by C3 | P4 |
| STT/TTS endpoints differ or rate-limit | Medium | Text fallback + device TTS; voice is last in the demo so it can be skipped | P4 |
| USDA 1,000/h limit hit during testing | Low | `foods` cache; DEMO_KEY only for smoke tests | P2 |
| Rive referenced-asset image swap unsupported in RN version | Medium | Layered fallback specified in INTEGRATIONS §4 | P4 |
| Scope creep in meal plan | High | Plan tab is the first thing cut at C3 if behind | P2 |
| Streak/score math disputes on stage | Low | Numbers shown match ALGORITHMS worked example; keep a printed copy | P3 |
